📊 FMCG Enterprise Intelligence Dashboard
### Advanced Sales, Distribution & Commercial Analytics Platform

**An end-to-end, interactive Business Intelligence portfolio project designed to transform FMCG transactional data into actionable business insights.**



## 📌 Project Overview

The **FMCG Enterprise Intelligence Dashboard** is a professional, six-page Business Intelligence solution developed using HTML5, CSS3, JavaScript, and Excel-based relational datasets.

The project provides comprehensive visibility into sales performance, distributor and retailer networks, revenue growth, profitability, sales target achievement, and field-force productivity.

It features **36 dynamic KPI cards, 24 interactive visualizations, and a Dynamic Executive Insights Engine**, enabling data-driven commercial decision-making.

## 🎯 Project Objectives

- Monitor primary and secondary sales performance.
- Analyze regional, territorial, and product-level revenue.
- Evaluate distributor and retailer network effectiveness.
- Track sales targets, achievements, and variances.
- Assess field-force productivity and visit effectiveness.
- Measure profitability, gross margins, and product performance.
- Generate dynamic business insights for executive reporting.
- Provide a centralized, interactive analytics environment.

## 🧠 Dynamic Executive Insights Engine

A key feature of this project is its automated, filter-responsive business insights system.

The engine evaluates:

1. **Revenue Momentum:** Sales trends and month-over-month performance.
2. **Geographic Performance:** Leading regions and revenue contribution.
3. **Product Mix:** Top-performing categories and product contribution.
4. **Profitability:** Gross margins and profitability movements.
5. **Channel Alignment:** Primary and secondary sales comparisons.
6. **Target Achievement:** Commercial achievement and performance gaps.

Insights dynamically update based on selected filters and can be exported as a text report.

**Note:** Insights are rule-based descriptive analytics, not generative AI or predictive machine learning.

## 🗄️ Data Model

The project uses a relational, star-schema-style data model containing **10 tables**.

**Dimension Tables:**
- DimDate
- DimProduct
- DimTerritory
- DimDistributor
- DimRetailer
- DimSalesRep

**Fact Tables:**
- FactPrimarySales
- FactSecondarySales
- FactTargets
- FactVisits

The dashboard connects analytical measures across sales, products, territories, distributors, retailers, and field representatives.

### Dataset Coverage

The sample dataset contains 1,000 records per fact table.

Primary sales, targets, and field visits cover January–February 2024. Secondary sales records cover January 2024 only.

The dashboard preserves actual data availability rather than treating missing periods as confirmed zero sales.



## 🚀 How to Run the Project

**Step 1:** Download or clone the GitHub repository.

**Step 2:** Extract the downloaded ZIP file if necessary.

**Step 3:** Locate the `index.html` file.

**Step 4:** Open the file using Google Chrome, Safari, Microsoft Edge, or another modern web browser.

**Step 5:** Explore all six dashboards using the sidebar navigation and interactive filters.

No software installation, API configuration, internet connection, or database server is required.

## ⚠️ Project Limitations

- Uses a static sample dataset embedded in the HTML application.
- Does not automatically refresh from Excel, ERP, or live databases.
- Executive insights are descriptive and rule-based.
- Historical sample data does not represent current business performance.
- The embedded data is accessible to anyone who downloads the published HTML file.
